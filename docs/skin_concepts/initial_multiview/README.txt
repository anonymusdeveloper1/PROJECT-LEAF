front.png - primary front view
left.png - character's left profile, nose points left in the image
back.png - back view

Each file shows one full-body character on white. Do not upload the four images as separate model-generation jobs.

MESHY WORKFLOW
1. Open Model > Image to 3D and upload front.png as the main image.
2. If your selected model/plan supports Multi-view, enable it and add left.png, back.png and right.png to the matching view slots.
3. If Multi-view is unavailable, use front.png on its own. Keep the other angles as design references.
4. Keep the neutral A-pose. These inputs are already clean; start with Image Enhancement off to preserve the design.
5. Optional description: meshy-description.txt. Image-to-3D interfaces may not show a text prompt field.
6. Inspect the hood, paws, gaps around the arms, separate legs and cape from all sides. Download the unrigged GLB.

The images show the entire cat so the outfit has clear proportions. The generated source model still needs fitting and rigging for the existing game cat. No model has been generated or added to the game by this reference task.
The bow, quiver and animated spirit flames are separate follow-up assets/effects and are intentionally omitted from the reconstruction inputs.
Colour/material finishing and effects are handled after the mesh is accepted. An untextured GLB is acceptable for our existing source pipeline.
