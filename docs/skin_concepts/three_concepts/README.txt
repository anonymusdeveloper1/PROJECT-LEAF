USING THESE WITH MESHY 6
Choose the skin you want, then upload its single PNG in Image to 3D. Each PNG is one complete front-facing A-pose reference with a white background. Generate each design separately using its own image.

Keep the neutral A-pose, visible tail and exposed face. Download an unrigged GLB when you are satisfied with the generated geometry. The source will then be fitted to the game's existing cat proportions, skeleton and animations.

The existing Cat Ranger concept was used as the face/proportion reference. Her face structure, muzzle, pink nose, whiskers, triangular ears, eye shape and expression remain identifiable across all three designs. Palette and outfit silhouette vary by theme.

All three concepts have empty paws and surface markings with clear solid geometry. The bow and animated magical effects can be added separately during game integration.

The matching *.prompt.txt files contain the exact prompts used with built-in image generation. These are the generation records; the PNG is the actual Meshy input.

This task creates concept images only. The owner generates the 3D source models in Meshy; no skin has been installed into the game.
